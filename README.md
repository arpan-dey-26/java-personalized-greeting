# Java Personalized Greeting

## Overview

This is a simple Java console application that takes the user's name and age as input and displays a personalized greeting. It also calculates how many years are left until the user turns 100.

## Features

- Takes user name as input
- Takes user age as input
- Displays a personalized greeting
- Calculates years remaining until 100
- Uses Java Scanner for input

## Technologies Used

- Java
- Scanner Class
